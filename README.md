## About me
My academic background is an M.Sc. in Data-Centric Engineering, majoring in Computer Vision and Pattern Recognition. In my Master's studies I focused on the following concepts:
- Advanced data analysis, data preprocessing, machine learning and pattern recognition
- Image preprocessing, digital imaging, image analysis, computer vision
- Bayesian statistics, continuous and statistical parameter estimation, numerical methods for PDEs

Currently I'm working full-time as a software developer, mostly with Python, FastAPI, .NET, C#, Visual Basic, JavaScript and SQL Server.

I'm enthusiastic about data science projects; I love to play with data and find meaningful insights in it. I always have a few hobby projects in development, and even more ideas for new projects on my mind. Some highlighted projects are listed below, feel free to take a look. Some repositories have better documentation than others...

## AI usage labels
Each project is labelled by how much generative AI was used to write its code. I use mainly Claude Code as my AI-assistant, occasionally also GitHub Copilot for inline suggestions and small code snippets.

| | Label | Meaning |
|:-:|-------|---------|
| <img src="assets/ai-free.png" width="40"/> | **AI Free** | No generative AI used for code, tests or docs. |
| <img src="assets/ai-minimal.png" width="40"/> | **AI Minimal** | Human-written code with some AI usage only for inline completion or small code snippets. Human-written code with AI-written docs fall into this category. |
| <img src="assets/ai-assisted.png" width="40"/> | **AI Assisted** | Human-led project where AI tools write substantial parts of the code under my direction, review and testing. Project that have started with low AI usage but nowadays are developed fully agentic fall into this category. |
| <img src="assets/ai-generated.png" width="40"/> | **AI Generated** | Code generated fully by AI. My role is mainly specifying, prompting and testing. This includes mainly projects where I have been only interested in the end result, not necessarily on how to get there. |
